# 🌿 Bloomwell

A gentle wellness journal. Log your mood, sleep, water, exercise, and symptoms every day, see your trends in charts, and spot simple patterns in your own data.

> **Disclaimer:** Bloomwell is a personal wellness tracker. It does not diagnose, treat, or provide medical advice.

## ✨ Features

- 🔐 Secure sign up and login using JWT and bcrypt
- 📔 Daily journal for mood, sleep, water, exercise, symptoms, and notes
- ✏️ Create, edit, and delete journal entries
- 📊 Weekly and monthly trend charts
- 🧠 Rule-based insights from your own logs, such as sleep versus mood
- 📱 Themed and responsive interface
- 👤 Per-user data access

## 🛠️ Tech Stack

### Backend
